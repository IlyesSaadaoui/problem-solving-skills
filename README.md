## 🚀 My Passion for CP

For me, competitive programming is not just about writing code:
it's a logic game where every problem is a puzzle waiting to be solved.

What I love about it:

- **Thinking before coding**: finding the key idea that turns a hard problem into a few simple lines.
- **Optimizing**: going from a slow O(n²) solution to a fast O(n log n) or O(n) one.
- **Improving every day**: every mistake (Wrong Answer, Time Limit Exceeded…) teaches me something new.
- **The challenge**: competing in contests, measuring myself against others, and climbing the rankings.

My goal is to build a real mastery of algorithms and data structures,
and to become faster and more precise at solving problems.
